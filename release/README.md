# Published records and historical release reports

The software and data records are public:

- [Software v1.0.0-rc2](https://doi.org/10.5281/zenodo.22949904)
- [Data and trained models v1.0.0-rc2](https://doi.org/10.5281/zenodo.22949906)

Use `PUBLISHED_PACKAGES.json` for the seven recommended complete data archives
and `../docs/REPRODUCTION.md` for installation and analysis instructions.
Current author information is given in `../CITATION.cff` and the Zenodo metadata.

The dated R2 reports, status files and `AUTHOR_APPROVAL_20260925.json` record
release preparation before publication. Their approval fields and pending states
refer to that period, rather than the current availability of the records.
Historical approval metadata are retained unchanged. See `../docs/VERSIONS.md`
for the archived manuscript and subsequent analysis additions.
