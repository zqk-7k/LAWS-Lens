# Numerical checks for localization and timing

## Injection localization

Direct and FFT matched-filter calculations and their normalization were
cross-checked for the injection localization workflow. The 2,700 validation and
test maps are linked to their corresponding noisy records.

## Runtime measurements

Pair calculations reproduced the reference scores within numerical tolerance
and recovered the same consensus ranks. The timing archive contains the input
manifest, model settings and numerical check records:
`../paper/runtime_evidence/LAWS_O3_FULL_RUNTIME_CURVE_EVIDENCE.zip`.

See `../paper/README.md` for the archive checksum and plotting instructions.
